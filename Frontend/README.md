# 🚀 TeamForge Frontend

Frontend for **TeamForge** — a developer collaboration platform where users can create projects, explore ideas, and collaborate with others.

This project is currently in the **initial development stage**, starting with React setup using Vite.

---

## 🛠 Tech Stack

* ⚛️ React (Vite)
* 🎨 CSS
* 🌐 REST API (Node.js backend)

---

## 📁 Project Structure

```
src/
│
├── App.jsx        # Main component
├── main.jsx       # Entry point
└── index.css      # Global styles
```

---

## ⚙️ Setup & Installation

```
# Clone the repository
git clone https://github.com/your-username/teamforge-frontend.git

# Navigate to the project folder
cd teamforge-frontend

# Install dependencies
npm install

# Start development server
npm run dev
```

---

## 🌍 Environment Variables

Create a `.env` file:

```
VITE_API_BASE_URL=http://localhost:4000/api/v1
```

---

## 🔗 Backend

This frontend will connect to the **TeamForge Backend API**.

Make sure backend server is running before integrating.
